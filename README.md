# 汀湾工坊 · Tidebay Atelier

可实际游玩的中文 3D 城市经营沙盘。首次从系统时间生成一座滨水城市，之后会继续本地存档。无需账户、云端素材或模型服务即可经营与探索。

## 怎么玩

- **单文件版本**：用支持 WebGL 2 的现代桌面浏览器打开 `Tidebay-Atelier.html`。图形引擎、字体和缩略图已内嵌。若文件查看器禁止存储或 WebGL，请下载后在浏览器打开。
- **开发 / 联网服务版**：安装 Node.js 20+，在此目录执行 `npm install`、`npm run dev`，打开终端给出的地址。`npm run build && npm run preview` 运行生产构建。
- `npm test` 运行确定性生成、住房、完整昼夜、财政结算与居民协议的测试。`npm run standalone` 重新生成单文件版本（另外需要 Python 3）。

| 操作 | 方式 |
| --- | --- |
| 平移 / 缩放 | 拖动地图或 WASD / 滚轮与右侧加减按钮；触屏可双指缩放 |
| 旋转 / 复位 | Q、E 或右键拖动 / 右侧取景框 |
| 选中设施 | 点击建筑或市政厅地标 |
| 建造 | 底部选择建筑，再点击薄荷色空地；R 旋转，Esc 取消。支持「定位空地」。 |
| 暂停 / 时间流速 | 空格或顶部暂停键；点击 1× 切换 1、2、4 倍速 |
| 建设目录 / 指南 | B / H 或 ? |
| 街区探索 | F 或右上角按钮进入或返回 |
| 漫游 / 观察 | WASD 行走、Shift 快步；桌面进入探索时请求锁定鼠标，直接移动鼠标环顾；触屏保留拖拽。 |
| 释放 / 重新锁定鼠标 | Esc 仅释放指针，保留当前位置；再次点击街景或「锁定鼠标」恢复。用于锁定的那次点击不会使用工具。 |
| 使用 / 切换工具 | 点击场景或 Enter / 数字 1–4；测绘镜可用右键切换望远 |

只有街区探索会申请鼠标锁定，俯瞰模式保留自由指针。打开菜单、切换标签页或离开探索时会释放指针。如果内嵌文件预览或浏览器拒绝申请，游戏会提示并退回拖拽模式，不会反复请求；要使用连续转向，请将新版 HTML 下载后在支持 Pointer Lock 的桌面浏览器中独立打开。

探索工具用于市政互动：**测绘狙击枪**读取设施与距离，**绿化步枪**在空地栽树，**信标手枪**留下坐标旗，**养护锤**近距修复设施。玩家不会穿过建筑，过河需走桥。模型中 1 单位约为 1 米。

## 经营与模拟

- 通过 CPU 哈希值噪声、多尺度 fBm 和种子随机流生成网格道路的偏移、河道、地块用途、建筑高度、植被及居民。设置中可输入种子重建，留空取当时的系统时间。新建前会二次确认。
- 九类可建设施：独栋住宅、花园洋房、银行、超市、发电厂、自来水厂、政府大楼、公司、公交站。住房有容量，建造需要可用地块与预算。
- 全市同类设施采用统一政策：储蓄年利率、股票每日涨跌、购物篮价格、电价、水费、所得税、月工资、单程票价，以及公交起终站。公交通过道路图寻路，往返配置的站点路口。
- 1× 时每 **1,200 秒一个昼夜**。前台模拟，后台标签页不会追算离线收入。24 次公共预算入账；居民工资、生活开支、年利率折算的储蓄利息与股票净值按日结算。财政预测和满意度随政策更新。这是经营模型，而非金融预测工具。
- 居民有姓名、职业、年龄、住所、个人储蓄、股票与日程。可搜索、分页查看、迁入、迁出或定位住所。街上的行人是部分居民的可视化代表。
- 自动存档使用浏览器 localStorage，每 12 秒及重要操作后保存。设置内可导出或恢复 JSON 备份。浏览器清理数据时本地档案也会清除，请保留备份。

## 可选的 LLM 居民

默认完全使用本地日程，**没有伪装成 LLM 的随机回复**。连接模型后，在单个居民详情内打开「LLM 自主决策」。模型只返回经校验的日常行动和一段中文想法。购物与乘车扣除居民余额，工作产生工资和税收，同一游戏小时不会重复结算 AI 行动。相应行人会尝试前往目标设施附近的路口。

1. **会话密钥**：设置 → 居民智能，输入自己的 OpenAI API Key，可指定模型。密钥只保存在内存，不写入存档、导出文件或日志。在线服务版通过同源 `/api/resident` 代理请求；下载的单文件版只在明确启用时直连 `api.openai.com`，需要网络及浏览器允许跨域访问。
2. **服务端兼容模型**：复制 `.env.example` 为 `.env.local`，配置 `LLM_BASE_URL`（含 `/v1`）、`LLM_MODEL`、可选 `LLM_API_KEY`，重启 Vite。也可通过环境变量设置。服务器不接受浏览器指定的任意代理地址。
3. 每游戏小时最多自动轮询一名已启用的 AI 居民；也可在个人详情主动对话。会产生所选提供商的费用。接口不可用时显示错误，不把本地台词冒充模型输出。

服务端密钥适合本地或可信用户部署。公开部署时，请另加自己的身份认证和预算额度。请勿把 `.env.local` 或真实密钥打包分享。

## 渲染与文件结构

Three.js PBR 材质（粗糙度、金属度、纹理、凹凸）、随时钟移动的阴影、天空与昼夜窗光、带扰动的水面平面反射。建筑、树木与车辆使用实例化几何。软件 GPU 在俯瞰时缓存静态场景的颜色和深度，保留水面、交通和人物的动态渲染。无 WebGL 2 时退回可经营的轻量 2D 地图；三维漫游需要 WebGL 2。

- `src/sim.js`：CPU 地图、模型与经济结算。
- `src/architecture.js`、`terrain.js`、`world.js`、`actors.js`：程序化建筑、地面/河流、渲染交互、交通寻路。
- `src/main.js`、`panels.js`、`style.css`：沙盘界面、政策、居民、备份、探索工具。
- `server/brain.js`、`src/resident-protocol.js`：模型代理与受限决策协议。
- `public/buildings`：直接用游戏建筑模型渲染的工具栏缩略图。
- `licenses/three-MIT.txt`、`public/fonts/OFL.txt`：Three.js 与 Manrope 字体许可。城市场景和界面图形均由本项目程序绘制。
